# 通用解压归档助手

把「下载 → 识别伪装 → 还原 → 校验 → 解压 → 分类归档」串成一步的桌面工具。

很多资源站会把压缩包伪装成视频/图片文件来规避审查，还会拆成分卷、加上密码。
手动处理要反复改名、猜密码、逐层解压，这个工具把整套流程自动化了。

## 功能

**伪装包识别与还原**
- 尾部反转型（Apate 类工具生成）：`文件 = [伪装头 L 字节][正文][反转(伪装头)][L 的 4 字节]`
- 追加型：真媒体文件后面直接跟着完整压缩包
- 检测是**结构性**的，不依赖文件名，也不限于某一家工具

**解压**
- 分卷压缩 `.001` / `.z01`，解完自动清理分卷
- 加密压缩包，支持多候选密码自动尝试
- 嵌套解压：解出来的内容里还有压缩包/分卷会继续解
- **解压前先做 CRC 校验**，下载不完整的文件会明确报出来，不会产生半截垃圾

**分类归档**
- 按类型分到 `<目标>\图片\` 和 `<目标>\视频\`
- 保留作品/日期子目录，自动折叠重复目录名
- 可选移动（归档后删源）或复制（保留源）
- 自动处理网盘下载文件的只读属性

## 运行

双击 `启动.bat`，或：

```bash
python main.py                     # 图形界面
python main.py --auto <源目录> \    # 批量自动模式
    --staging D:\_staging \
    --dest H:\归档 \
    -p 密码1 -p 密码2
```

需要 Python 3.9+（自带 tkinter）。解压引擎是自带的 `bin\7za.exe`，无需另装 7-Zip。

## 界面

**解压页**

| 项目 | 说明 |
|---|---|
| 输入文件/文件夹 | 可多选文件（`;` 分隔），或选文件夹批量处理 |
| 输出目录 | 每个压缩包解到以它命名的子目录 |
| 密码 | 每行一个，依次尝试；无密码留空 |
| 自动处理嵌套分卷 | 自动接着解 `.001`/`.z01` |

**分类归档页**

| 项目 | 说明 |
|---|---|
| 待归档目录 | 通常是解压输出目录 |
| 归档到 | 例如 `H:\赏花阁` |
| 移动/复制 | 移动=归档后删源；复制=保留源 |

## 批量模式的磁盘策略

`--auto` 逐个处理：解压到暂存区 → 归档到目标 → 删源包和暂存。
峰值占用接近**单个**压缩包，所以 50 GB 的队列也能在剩余空间不大的盘上跑完。

已处理文件名记录在 `<暂存目录>\_processed.txt`，中断后重跑会跳过已完成的。

## 目录结构

```
解压助手/
├── main.py            入口（GUI / --auto）
├── 启动.bat           双击启动
├── bin/7za.exe        解压引擎（7-Zip 官方独立版）
└── app/
    ├── sevenzip.py    7za 封装（列表/校验/解压）
    ├── disguise.py    伪装检测与还原算法
    ├── pipeline.py    主流程（还原→校验→解压→递归→归档）
    ├── cli.py         批量/命令行模式
    └── gui.py         图形界面
```

## 技术要点

伪装还原（`disguise.py`）：

```
文件布局 = [伪装头 L 字节][正文][反转(伪装头)][L 的 4 字节小端]
还原     = 反转(末尾 L 字节) + 正文
```

`L` 直接存在文件最后 4 字节，不需要猜测，任意大小都能精确还原。
检测时还会验证还原结果确实以压缩包签名开头、原文件确实以媒体签名开头，
避免把普通视频误判成伪装包。

## 注意

- 校验失败通常意味着**下载不完整**（文件里有成片 0 区域），需要重新下载。
- 网盘下载的文件常带只读属性，程序在覆盖/删除前会自动清除。
- 归档采用「复制 → 校验大小 → 删除源」的方式，移动失败不会丢文件。
