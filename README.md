# 通用解压归档助手

把「扫描收件箱 → 识别伪装 → 还原 → 校验 → 解压 → 递归解套娃 → 分类归档」
串成一步的工具。

资源站常把压缩包伪装成视频/图片、拆成分卷、加密码、内层再套一层压缩包。
手动处理要反复改名、猜密码、逐层解压；这套工具把它全自动化。

## 快速使用（一键）

桌面双击 **一键解压并看图**：

```
扫描收件箱 → 解压（含套娃）→ 分类归档 → 刷新清单 → 自动打开刚解压的内容
```

一条龙跑完，完了直接弹出看图软件，不用手动找目录。

另外两个桌面快捷方式：

| 快捷方式 | 用途 |
|---|---|
| **看刚解压的** | 只看上次解压了什么，不重新处理 |
| **解压助手** | 打开图形界面（要精细控制时用） |

命令行等价写法：

```bash
python 一键.py                 # 一键处理并打开
python 一键.py --no-open       # 处理但不打开
python 一键.py --delete-source # 成功后删除源压缩包
```

## 快速使用（收件箱模式）

```bash
# 1. 把压缩包丢进 D:\dowm
# 2. 密码写进 D:\dowm\解压密码.txt（每行一个）
# 3. 跑一条命令
python 收件箱.py
```

它会自动完成：识别 → 解压 → 分类归档 → 刷新检索清单。

**默认保留源压缩包**，确认结果没问题后再删：

```bash
python 收件箱.py --delete-source      # 各道检查都通过才删源
python 收件箱.py <收件目录> <归档目录>  # 自定义目录
```

## 能处理什么

**伪装包**（按结构检测，不靠文件名）
- 尾部反转：`文件 = [伪装头 L 字节][正文][反转(伪装头)][L 的 4 字节]`
- 追加型：真媒体文件后直接跟着压缩包
- 追加型的定位方式是**先解析媒体容器结构**（MP4 box 链 / JPEG EOI / PNG IEND），
  从容器结束处往后找**最外层**的压缩包 —— 这样即使文件末尾还粘着别的东西
  （比如一小段无效数据或第二个包），也能找对位置
- 伪装扩展名：`xxx.7z.001.pdf`、`xxx.zip.mp4`

**重复下载去重**
- 浏览器重复下载会生成 `xxx(1).mp4` 这种副本，内容与原件逐字节相同
- 只按"文件大小相同"时才做完整比对，避免无谓读盘；重复项自动跳过并报告

**分卷与加密**
- `.001` / `.z01` 分卷，解完自动清理
- 多候选密码依次尝试

**套娃包**（三层保险，避免漏解）
1. 分卷 `.001`/`.z01`
2. 压缩包后缀 `.7z/.zip/.rar`
3. 上面都不匹配时，**按文件头嗅探** —— 应对 `课件.7z删除`、`.bin` 这类改名内层包

**残缺失效包**
- 解压前做 CRC 校验，不完整的会明确报出
- **抢救式解压**：仍尽力解出未损坏的部分，而不是直接放弃

## 安全机制（重要）

处理别人的资源包，最怕"解压失败还把源文件删了"。本工具有两道闸门：

1. **体积合理性检查** —— 解出内容为 0 字节、或不足源包 1% 时判定异常，**拒绝删除源文件**
2. **归档零遗留检查** —— 任何文件没能安全归档（含未知类型），保留暂存内容 + 源包并报错

另外：未知类型的文件不会被丢弃，统一归入 `其他/`。

## 归档规则

| 来源 | 去向 |
|---|---|
| 图片（13 种扩展名） | `<归档>\图片\<作品>\...` |
| 视频（17 种扩展名） | `<归档>\视频\<作品>\...` |
| 其它 | `<归档>\其他\<作品>\...` |

保留作品/日期子目录，自动折叠重复的目录名。

## 性能

归档是**多线程 + 裸读写**：

- 同盘搬迁用 `os.replace`（瞬时改名，零拷贝）
- 跨盘用线程池并发复制（默认 8 线程，实测 4 倍提速）

实测（1050 个小文件 / 245 MB，D→H 跨盘）：

| 线程数 | 耗时 | 提速 |
|---|---|---|
| 1（旧版行为） | 16.3s | 基准 |
| 8（默认） | 4.1s | 4.0× |

对比 `shutil.copy2` 串行：它会逐文件同步时间戳等元数据，在慢盘上开销极大 ——
换成裸读写后同样数据从 54 MB/s 提升到 1077 MB/s。

**暂存目录要放在快盘上**：每个文件要写暂存区两次再写目标区一次。
放在慢速外置盘（实测 52 MB/s）会拖慢十几倍。

## 检索清单

```bash
python 建索引.py          # 默认扫 H:\赏花阁
```

生成两个文件（`收件箱.py` 每次归档后会自动刷新）：

- **`索引.csv`** —— 每个文件一行：类型,作品,文件名,相对路径,大小KB,修改日期
- **`作品清单.csv`** —— 每个作品一行：类型,作品,文件数,总MB,最新日期（按体积降序）

用 Excel 打开可排序筛选；配合 FastStone Image Viewer 用浏览面板定位即可。

## 密码热加载

密码不用重启程序就能生效 —— 三种来源自动合并去重：

1. **密码文件**（默认 `D:\dowm\解压密码.txt`，每行一个）
2. **说明文件自动提取** —— 收件目录里任何 `.txt` 出现 `密码:xxx` 都会被抓取
3. **目录名识别** —— 像 `解压密码：xiaohutao` 这样的文件夹名也会被提取

界面的「密码」标签页可以增删密码，写入文件后**立刻对后续压缩包生效**；
跑批处理时在外部编辑密码文件也一样能热加载（每 1.5 秒检测一次）。
手动加错了密码也没关系，会继续尝试列表里的其他候选。

## 图形界面

```bash
python main.py            # 或双击 启动.bat
```

四个标签页：

| 标签 | 用途 |
|---|---|
| **收件箱** | 一键扫描收件目录 → 解压 → 分类归档 → 刷新清单（推荐日常用） |
| **解压** | 手动选文件/文件夹解压，可选是否扫子目录、是否解内层套娃 |
| **分类归档** | 把已有目录按类型分好，可选移动或复制 |
| **密码** | 增删密码、从说明文件重新提取、指定密码文件位置 |

「收件箱」页有 **预览待处理** 按钮（先看清单再动手）和 **停止** 按钮（当前包处理完就停）。
删除源压缩包是**单独一个开关，默认关闭**，确认结果无误后再勾选。

## 环境

Python 3.9+（自带 tkinter）。解压引擎是自带的 `bin\7za.exe`，无需另装 7-Zip。

## 批量模式

```bash
python main.py --auto <源目录> \
    --staging D:\_staging --dest H:\归档 \
    -p 密码1 -p 密码2
```

逐个处理：解压到暂存 → 归档到目标 → 删源与暂存，峰值只占一个包的空间。
已处理文件名记在 `<暂存目录>\_processed.txt`，中断重跑会自动跳过。

